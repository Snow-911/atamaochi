# アタマオチ
ジャンルと制限時間を選び、お題のひと言から即興でトークします。ひとりプレイはブラウザで index.html を開いて遊べます。

## オンライン
公開サイトでルームを作成し、招待リンクを共有してください。招待リンクは端末ごとに暗号化したデータを EMQX の公開 MQTT ブローカー経由で中継します。コード入力では PeerJS の直接接続を使用します。離れて遊ぶときの音声は別途通話を使用してください。

プレイヤーは最大8人で、観戦者を含むルーム定員は16人です。ホストはロビーでトーク順をドラッグして変更できます。試合中の入室は観戦になり、ロビーでプレイヤーに切り替えられます。各トークは話者以外のプレイヤーと観戦者が1人1票で判定し、「オチた」が過半数なら成功、同票は失敗、投票者がいない場合は判定なしです。最終結果の6秒後に同じロビーに戻ります。
