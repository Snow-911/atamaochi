# アタマオチ
GitHub Pages の公開フォルダーにこの ZIP の中身を展開してください。ビルド・API キーは不要です。
ホストはジャンル、時間、ラウンド数を決めて「ルームを作成」。ほかの参加者は同じサイトで6桁のコードを入力します。2〜8台が参加できます。ホストが全員の参加を確認して開始し、各ターンのお題表示と採点を操作します。音声は配信しないので、離れて遊ぶ場合は別途通話してください。
接続の仲介に PeerJS Cloud を利用します。ネットワークによっては端末間通信が成立しません。プレイ中は全員がページを開いたままにしてください。ホストを含め途中で切断するとゲームは終了し、進行状況は保存されません。
