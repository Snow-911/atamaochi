# 効果音のクレジット

- 開始・タイマー音は Alexander Holm の [Salamander Grand Piano](https://github.com/Tonejs/audio/tree/master/salamander)（[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)）のピアノ録音を移調・編曲し、短い合図に編集しました。
- ガヤは Ch0cchi の [Small group laughter](https://commons.wikimedia.org/wiki/File:Small_group_laughter.ogg)（[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)）の録音を抜粋し、モノラル化、音量調整、フェード処理を行いました。

- 追加のガヤは ezwa の [Laughter](https://commons.wikimedia.org/wiki/File:Laughter.ogg) と [Bursting out laughing](https://commons.wikimedia.org/wiki/File:Bursting_out_laughing.ogg)（パブリックドメイン）から抜粋し、音量とフェードを調整しました。

- トーク終了音は[効果音ラボ「ちゃんちゃん♪3」](https://soundeffect-lab.info/sound/anime/)をゲーム内で使用しています。[利用規約](https://soundeffect-lab.info/agreement/)が適用されます。
